# Socially inclusive energy system designs and practices - Energy systems, models and justice

This repository contains the data and scripts necessary to recreate some of the figures and additional analysis to my PhD thesis, titled _Socially inclusive energy transitions - Energy systems, models and justice_.

Figure 1.1 can be recreated using `scripts/climate_change_figures.ipynb` and figure 1.2 using `scripts/map.ipynb`. 

Figure 1.1 is based on data from [Andrew and Peters, 2022](https://zenodo.org/records/7215364) and the [World bank](https://data.worldbank.org/indicator/NY.GDP.PCAP.CD). To regenerate figure 1.2 one need European shapefiles from [EUROSTAT](https://ec.europa.eu/eurostat/web/gisco/geodata/statistical-units/territorial-units-statistics) as well as model results. Model results can be provided upon request.

In addition to generating the base figure, some additional customisation is necessary, e.g. with [Inkscape](https://inkscape.org/).
